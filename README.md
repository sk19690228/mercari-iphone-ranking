# 型落ちiPhone おすすめランキング

固定済みのメルカリ検索条件からiPhone 16シリーズの新着商品を取得し、中古平均価格に対する割引率が高い順でおすすめランキング1～3を自動作成するPWAです。

## 主な機能

- アプリ起動時に新着商品を自動検索
- メルカリの商品価格専用メタ情報から出品価格を優先取得
- 割引率の高い順（お得な順）で候補を並べ替え
- 上位3件を「おすすめランキング1～3」として自動選定
- 採用ボタンを使わず、上位3件を確認・修正欄へ自動反映
- 3件分の商品タイトル、商品ページURL、メルカリアフィリエイトリンクを編集
- ページを表示するたびにメルカリアフィリエイトリンク入力欄をクリア
- 「リンク」ボタンから商品ページを新しいタブで開く
- 商品URLから `afid=9289281257` 付きアフィリエイトリンクを生成できる場合は自動入力
- おすすめランキング1～3を1枚のPNG画像としてダウンロード
- ランキング画像へ各商品の画像を掲載
- アフィリエイトリンク入力確定時の自動更新と、更新ボタンによるランキング画像の再生成
- 更新ボタンを押すたびに新しい画像データへ差し替えてプレビューを表示
- 3件分のメルカリPR投稿文を指定テンプレートで自動生成
- PR投稿文の商品名を「機種名 容量」（例：`iPhone 16 128G`）へ統一
- PR投稿文を「ランキング・機種名/容量/価格・アフィリエイトリンク」の簡潔な形式で生成
- PR投稿文の見出しを「メルカリ おすすめiPhone」、順位名を「ランキング①～③」で表示
- 1位の商品詳細から、iPhone 17とiPhone 16の機能差・価格差を含む120文字以内のおすすめ文を作成・コピー
- おすすめ文作成欄をランキング1位のアフィリエイトリンク入力欄の直下に配置
- おすすめ文の冒頭を「作成日／最新オススメランキング１位🥇／ここがオススメ✨」の3行で表示
- 1位の商品欄は「商品情報入力」に変更し、作成・コピー欄をPR表記の直前へ配置
- 中古平均価格一覧を非表示にし、価格データの更新日時だけを表示
- 商品画像、商品詳細、Amazon情報、従来のXポスト用画像生成を廃止
- Gmailの読取・検索・ラベル操作なし

メルカリがJavaScript表示だけを返した場合は、公開検索URLだけをJina Readerへ送るフォールバックを使用します。GAS URL、`APP_TOKEN`、Gmail情報は送信しません。

新しいApps Scriptプロジェクトの設定方法は `MANUAL_URL_GAS_SETUP.md` を参照してください。

`main` ブランチへ反映すると、同梱のGitHub Actionsが新アプリをGitHub Pagesへ公開します。
